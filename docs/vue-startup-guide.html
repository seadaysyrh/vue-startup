どちらも .vue をブラウザが読める HTML・JS・CSS に変換します。違うのは、その結果をどう使うかです。

npm run serve

localhost は「このパソコン自身」、8080 は「その中の 8080 番の窓口（ポート番号）」という意味です。

publicPath

build した HTML をダブルクリックすると真っ白だった理由

変換はうまくいっていました。問題は、HTML が JS ファイルを探す場所の書き方でした。初期設定のビルドでは、dist/index.html にこう書かれます。

<script src="/js/app.8ae8acae.js"></script>

先頭の / は「一番上の階層から探す」という意味です。何が「一番上」になるかは、開き方で変わります。

サーバーで開くhttp://example.com/js/app.js見つかる
ダブルクリックD:\js\app.js（Dドライブ直下）無い
JS が読み込めないので、空の <div id="app"> だけが表示されて真っ白になります。F12 のコンソールには ERR_FILE_NOT_FOUND が出ます。
このプロジェクトでは vue.config.js に publicPath: './' を追加済みです。今の dist/index.html は js/app.8ae8acae.js（HTML と同じフォルダから探す）になっているので、ダブルクリックでも表示されます。

注意：あとで vue-router の履歴モード（URL が /about のようになる形）を使うと、ダブルクリックではまた表示が崩れます。そのときは npx serve dist のように簡易サーバーで dist を開いて確認してください。

Next

次にやってみること

上から順に、少しずつ難しくなります。どれも npm run serve を起動したまま試すと、保存するたびに結果が見えます。

  1. STEP 1文字を変えるApp.vue の msg="…" を好きな文字にして保存し、画面が変わるのを確認する。
  2. STEP 2いらないものを消すHelloWorld.vue のリンク集を消して、自分の文章に置き換える。
  3. STEP 3自分の部品を作るcomponents/ に新しい .vue ファイルを作り、App.vue で読み込んで表示する。
  4. STEP 4動きをつけるdata() で数字を持ち、ボタンを押すと増えるカウンターを作る（@click を使う）。
vue-startup（Vue 3 + Vue CLI 5）用のガイドです。Vue CLI は現在メンテナンスのみの状態です。新しいプロジェクトを作るときは Vite（npm create vue@latest）が公式のおすすめです。
